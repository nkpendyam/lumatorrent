# Security Policy

Report security issues privately through GitHub Security Advisories once the repository is published.

## Security-sensitive areas

- Path handling.
- File deletion.
- Remote/local API.
- Torrent metadata parsing.
- Auto-update.
- Native sidecar execution.
- File opening and risky file warnings.

## Non-goals

LumaTorrent is not an anonymity tool. Do not market it as one.
