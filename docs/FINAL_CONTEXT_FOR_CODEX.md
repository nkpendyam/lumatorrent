# Final Context for Codex

## How to avoid context waste

Codex should load only the relevant context pack for the milestone.

## Context packs

- preflight: repo scripts, package.json, Codex handoff
- design: design bible, UI specs, design tokens
- frontend: app shell, components, state management
- backend: engine API, local security, sidecar playbook
- file-safety: path safety, delete-to-trash, threat model
- diagnostics: Download Doctor specs, engine events
- release: packaging, signing, QA, GitHub automation

## Do not load everything unless doing a final review.

For each session:
1. Load the milestone docs.
2. Scan related files.
3. Implement.
4. Test.
5. Summarize.
