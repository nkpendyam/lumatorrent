## Must not be automated blindly

- Signing certificates.
- Apple Developer credentials.
- Windows signing keys.
- GitHub personal access tokens.
- VPN credentials.
- Private tracker credentials.
- Running unknown web scripts.

## Recommended workflow

1. Use fast model for file discovery.
2. Use strong model for implementation plan.
3. Use fast model for repetitive edits.
4. Use targeted tests.
5. Use strong model for review.
6. Update docs and task queue.
