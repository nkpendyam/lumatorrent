# Privacy Policy Draft

LumaTorrent should be privacy-respecting by default.

## Defaults

- No ads.
- No telemetry by default.
- No tracking pixels.
- No account required.
- Download history stays local.

## Optional reporting

If crash reporting is added later:

- opt-in only,
- clear preview of data collected,
- no file names, magnet links, info hashes, or tracker URLs by default,
- user can disable at any time.

## Remote dashboard

Remote dashboard is disabled by default and must require explicit user setup.
