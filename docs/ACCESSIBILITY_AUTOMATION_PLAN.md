# Accessibility Automation Plan

## Required tools
- Playwright accessibility smoke flows
- keyboard traversal tests
- axe-compatible checks when dependency is added
- manual screen-reader pass before beta

## Required checks
- visible focus
- keyboard operation
- labels on icon buttons
- no color-only status
- reduced motion
- semantic headings
- dialog focus trap
- Escape closes modal/drawer

## Release requirement
No release candidate can ship without completing the accessibility checklist.
