# Product Requirements Document

## Product name

LumaTorrent

## Vision

A premium, minimal, open-source torrent downloader for legal files that explains what is happening and helps users fix slow downloads.

## Target users

- People downloading Linux ISOs and open-source software.
- Researchers downloading public datasets.
- Developers distributing large legal artifacts.
- Power users who want a better torrent UI without losing control.

## Main differentiation

Existing clients often expose raw protocol details without context. LumaTorrent should provide:

1. Beautiful minimal dashboard.
2. Smart speed diagnosis.
3. Safe file handling.
4. Expert mode without cluttering beginner UX.
5. Modern 2026 desktop polish.

## Core promise

Not “always faster.”

Correct promise:

> “Understand and optimize your downloads with clear diagnostics and safe defaults.”

## MVP scope

- Add magnet link.
- Add `.torrent` file.
- Start/pause/resume/remove.
- Show progress, speed, ETA, health.
- File list and file priority UI.
- Download Doctor diagnostics.
- Safe remove/delete flow.
- Dark/light/system theme.
- Simple mode and Expert mode.
- Local settings persistence.
- Legal-use copy and onboarding.

## Not in MVP

- Built-in torrent search.
- Piracy-site integrations.
- Anonymous routing.
- Mobile app.
- Plugin marketplace.
- Cloud sync.
- Remote dashboard.

## Success criteria

- A beginner understands the app within 10 seconds.
- A power user can access trackers, peers, ratio, DHT, and advanced controls.
- Slow downloads produce actionable explanations.
- File deletion is safe and reversible where possible.
- UI remains smooth with 100+ torrents.
- App restarts without losing state.
