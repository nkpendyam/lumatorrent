# Legal and Branding Policy

## Allowed positioning

- Legal torrent downloader.
- Open-source distribution.
- Linux ISO downloader.
- Public dataset transfer.
- Creative Commons media.
- Developer artifact distribution.

## Disallowed positioning

- Piracy downloader.
- Movie downloader.
- Anonymous illegal downloading.
- Built-in torrent-site search.
- Scraping copyrighted-content sites.

## UI copy

Use:

```text
Add magnet link or .torrent file for legal downloads.
```

Do not use:

```text
Search movies, games, shows.
```

## Contribution policy

Reject PRs that add piracy-site integrations, illegal search providers, or features intended to bypass copyright enforcement.
