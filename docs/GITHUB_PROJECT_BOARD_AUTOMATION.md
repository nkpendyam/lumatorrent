# GitHub Project Board Automation

## Goal
Create a GitHub project board that maps milestones to issues and status.

## Required preconditions
- GitHub CLI installed.
- User authenticated.
- Required scopes available.
- Repo exists.

## Board columns/status values
- Backlog
- Ready
- In progress
- Review
- Blocked
- Done

## Important
The script must dry-run by default. Use `--execute` only after reviewing generated commands.
