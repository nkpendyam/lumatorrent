# Native Engine API Contract

The native engine must implement this contract regardless of whether it is running in stub mode or libtorrent mode.

## Security requirements

- Bind to loopback only by default.
- Require `X-Luma-Engine-Token` for every request.
- Require `X-Luma-Engine-Version: v1` for authenticated requests.
- Token must be generated by the Tauri host and passed through environment variable or inherited secure channel.
- Never accept save paths containing traversal, absolute torrent-internal paths, or null bytes.
- Never delete files unless the desktop app sends an explicit `delete_files: true` after user confirmation.

## Endpoints

### `GET /v1/health`

Response:

```json
{
  "ok": true,
  "apiVersion": "v1",
  "engineVersion": "native-0.1.0",
  "torrentBackend": "stub",
  "uptimeSeconds": 12,
  "startedAtIso": "2026-05-15T00:00:00Z"
}
```

### `POST /v1/torrents/magnet`

Request:

```json
{
  "magnetUri": "magnet:?xt=urn:btih:...",
  "savePath": "/safe/path",
  "startPaused": false,
  "selectedFiles": null
}
```

Response:

```json
{
  "torrentId": "sha256-or-infohash-derived-id",
  "status": "metadata"
}
```

### `POST /v1/torrents/file`

Request:

```json
{
  "torrentFilePath": "C:/Downloads/legal-release.torrent",
  "savePath": "C:/Downloads/LumaTorrent",
  "startPaused": false
}
```

Response:

```json
{
  "torrentId": "v1-info-hash",
  "status": "checking"
}
```

        "progress": 0,

### `POST /v1/torrents/:id/pause`

### `POST /v1/torrents/:id/resume`

### `POST /v1/torrents/:id/remove`

Remove request:

```json
{
  "deleteFiles": false
}
```

### `GET /v1/torrents/:id/diagnostics`

Returns the Download Doctor model used by the UI.
