# Accessibility Checklist

- [ ] Full keyboard navigation for dashboard, add modal, details panel, and settings.
- [ ] Focus rings visible in light and dark mode.
- [ ] Health status uses text, not color alone.
- [ ] Reduced-motion mode disables non-essential animations.
- [ ] Buttons have accessible names.
- [ ] Dialogs trap focus and restore focus on close.
- [ ] Contrast checked for primary text, secondary text, badges, and buttons.
- [ ] Screen-reader labels for progress bars include percentage and status.
- [ ] Table mode supports keyboard row navigation.
